- 📄 **Predicting Severity of Type 2 Diabetic Retinopathy Using Retinal Fundus Images with New Deep Learning Architectures from the Inception and ResNet Families**
  - **Publisher**: IEEE Xplore (Conference Paper, May 2025)
  - **URL**: [Read on IEEE Xplore](https://ieeexplore.ieee.org/document/10987517)
  - **Abstract Summary**: Evaluated Inception-V4, ResNet-V1, and ResNet-V2 CNN models using transfer learning on fundus images from 9,948 patients. The ensemble model achieved 94.21% accuracy and 98.53% AUC, offering early diabetic retinopathy classification for clinical support.
